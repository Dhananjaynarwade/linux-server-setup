# DevOps Project 1: Linux Server Setup

## Project Objective

Set up an Ubuntu Linux server on AWS EC2 and install basic DevOps tools required for future CI/CD projects.

## AWS Configuration

- Instance Name: `DevOps-Project-1-Linux-Server`
- Operating System: Ubuntu Server 26.04 LTS
- Instance Type: `t3.micro`
- Key Pair: RSA `.pem`
- Security Group: SSH Port 22
- Storage: 8 GiB `gp3`
